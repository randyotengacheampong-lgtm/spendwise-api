# 💰 SpendWise API — Fintech Expense Tracker

A production-ready Fintech backend built with FastAPI.

### Features
- Add / List / Delete Expenses
- Add / List Incomes
- Auto-calculates Balance = Income - Expenses
- Analytics endpoint

### Stack
FastAPI | Python | SQLAlchemy | SQLite

### Run Locally
pip install -r requirements.txt
uvicorn main:app --reload --port 8001

Open: http://127.0.0.1:8001/docs
